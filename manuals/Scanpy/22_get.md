# Get object from `AnnData`: `get`[#](https://scanpy.scverse.org/en/stable/api/get.html#module-scanpy.get)

The module `sc.get` provides convenience functions for getting values back in useful formats.

| get.var_df | Return values for observations in adata. |
|------------|------------------------------------------|
| get.pca | Return PCA results as anAnnDataindexed by component. |
| get.rank_genes_groups_df | Getscanpy.tl.rank_genes_groups()results in the form of aDataFrame. |
| get.aggregate | Aggregate data matrix based on some categorical grouping. |
