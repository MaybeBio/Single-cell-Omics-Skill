Note

For reading annotation use [pandas.read_…](https://pandas.pydata.org/pandas-docs/stable/user_guide/io.html#io) and add it to your [`AnnData`](https://anndata.scverse.org/en/stable/generated/anndata.AnnData.html#anndata.AnnData) object. The following read functions are intended for the numeric data in the data matrix `X`.
