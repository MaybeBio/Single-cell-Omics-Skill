# External API[#](https://scanpy.scverse.org/en/stable/external/index.html#module-scanpy.external)

Deprecated since version 1.13.0: `scanpy.external` is deprecated and will be removed in a future release. For tools that integrate well with scanpy and anndata, or to submit your own, see the [scverse ecosystem](https://scverse.org/packages/#ecosystem).

Import Scanpy’s wrappers to external tools as:

```
import scanpy.external as sce
```
